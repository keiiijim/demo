G1: ADG だけ G2: 他社（ダミー）が勝つ 本番の prebid.js で比較

新しいマニュアル（Prebid.js 10 以降向け）のネイティブスタイルを入稿した GAM の広告ユニット /18339668/test_demo/test_prebid_native_v10 に、実際に GAM を通して広告を出すページです。広告は GAM の safeframe（別オリジンの iframe）の中に描画されるので、i アイコンのリンクは DevTools で確かめます。

  • このページを開くと、本番の広告枠（110569）と GAM に実際にリクエストが飛びます。確認に必要な回数だけ開いてください。
  • ADG のテスト配信は一定の割合で noBid を返します。G1 で枠が空のときは、2〜3 回読み込み直してください。
  • 確かめ方: DevTools の Elements で広告の iframe（google_ads_iframe_…）の中を開き、#prlinkurl の href を下の「期待する href」と見比べます。Console の上部のコンテキスト（top）を iframe に切り替えて document.getElementById('prlinkurl').href と打っても確かめられます。
